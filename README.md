# Zolotaya Korona × Agrobank — рекламный лендинг

Рекламный лендинг продукта **«Zolotaya Korona onlayn»** (Agrobank).
Многоязычный статический сайт: узбекская версия — основная (`/`), также
доступны русская (`/ru/`) и английская (`/en/`) версии.

## Статус проекта

- ✅ Инициализация репозитория и структуры проекта — **сделано**.
- ⏳ Контент, верстка секций (hero, шаги, форма и т.д.), переводы —
  **не начаты**.

## Стек

- [Eleventy (11ty)](https://www.11ty.dev/) — генератор статики.
- Чистый CSS (без Tailwind/Bootstrap и любых CSS-фреймворков), дизайн-токены
  через CSS custom properties.
- Чистый JS (vanilla, без React/Vue и сборочных фреймворков).
- npm — менеджер пакетов.

## Структура проекта

```
/
├── src/
│   ├── _data/
│   │   ├── uz.json         # тексты интерфейса на узбекском (пока {})
│   │   ├── ru.json         # тексты на русском (пока {})
│   │   └── en.json         # тексты на английском (пока {})
│   ├── _includes/
│   │   └── layout.njk      # базовый HTML-каркас (doctype, head, meta, css/js)
│   ├── assets/
│   │   ├── logo/            # сюда нужно положить logo.png (сейчас пусто)
│   │   ├── fonts/           # сюда нужно положить файлы фирменного шрифта (сейчас пусто)
│   │   ├── css/
│   │   │   └── tokens.css   # дизайн-токены: цвета, шрифт (без верстки блоков)
│   │   └── js/
│   │       └── main.js      # основной JS-файл (пока заглушка)
│   ├── uz.njk               # страница на узбекском, выходной путь "/"
│   ├── ru.njk                # страница на русском, выходной путь "/ru/"
│   └── en.njk                # страница на английском, выходной путь "/en/"
├── .eleventy.js              # конфиг 11ty: passthrough copy assets, input/output dirs
├── package.json
├── .gitignore
└── README.md
```

## Как запустить локально

```bash
npm install       # установить зависимости
npm run dev        # локальный сервер разработки с live reload
npm run build       # сборка статики в папку _site/
```

## Логотип и шрифты

- Логотип нужно положить в `src/assets/logo/logo.png`.
- Файлы фирменного шрифта нужно положить в `src/assets/fonts/` — после
  этого в `src/assets/css/tokens.css` нужно будет добавить правило
  `@font-face` (место для него уже помечено комментарием в файле).
